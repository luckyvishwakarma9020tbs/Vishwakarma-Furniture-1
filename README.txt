Vishwakarma Furniture - app

GitHub Pages par chalane ke steps (sab files seedhi upload karo, koi folder nahi):
1. Zip ko pehle phone/PC me Extract karo.
2. github.com par naya PUBLIC repository banao (jaise: vishwakarma).
3. Add file > Upload files: andar ki SABHI 8 files upload karo (index.html, manifest.json, sw.js, jspdf.min.js, icon-192.png, icon-512.png, icon-maskable-512.png, README.txt). Commit karo.
4. Settings > Pages > Branch: main, folder: / (root) > Save.
5. 1-2 minute baad link milega: https://USERNAME.github.io/vishwakarma/

APK banane ke liye:
1. pwabuilder.com kholo, upar apna GitHub Pages link daalo.
2. Package for stores > Android > Generate. APK download karo.

Note: data usi phone/browser me save hota hai. Browser data clear karoge to data ud jayega.
